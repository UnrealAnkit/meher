================================================================================
                          DATABASE STRUCTURE
================================================================================

TABLE: calendar_events

id                   UUID (Primary Key)
title                VARCHAR(255) - Event name
description          TEXT - Facilitator info
tag                  VARCHAR(100) - UPCOMING/FEATURED/POPULAR
price                VARCHAR(50) - e.g., "Rs 500.00"
duration             VARCHAR(50) - e.g., "60 Minutes"
time_slots           TEXT[] - ["10:00 AM", "11:00 AM"]
image_url            TEXT - Public Supabase Storage URL
expanded_description TEXT - Full event details
created_at           TIMESTAMP - Auto-set on creation
updated_at           TIMESTAMP - Auto-set on updates

INDEXES:
  - idx_calendar_events_created_at (for sorting)
  - idx_calendar_events_tag (for filtering)
  - idx_calendar_events_title (for searching)

                          TROUBLESHOOTING
================================================================================

ERROR: "Could not authenticate"
FIX: Create user in Supabase Auth (Authentication → Users)

ERROR: "Failed to fetch events"
FIX: Check RLS policies, verify database connection

ERROR: "Failed to upload image"
FIX: Create event-images bucket and make it public

ERROR: Image not showing
FIX: Check file < 10MB, try different format, check image URL

ERROR: Blank dashboard
FIX: Normal when empty - create first event or insert sample data

ERROR: CORS errors
FIX: Add your URL to Project Settings → API → CORS

ACCESSING EVENTS FROM FRONTEND:

```typescript
import { supabase } from '../lib/supabase';

// Get all events
const { data: events } = await supabase
  .from('calendar_events')
  .select('*')
  .order('created_at', { ascending: false });

// Filter by tag
const { data: upcoming } = await supabase
  .from('calendar_events')
  .select('*')
  .eq('tag', 'UPCOMING');

// Display in component
events.map(event => (
  <EventCard key={event.id} {...event} />
```

================================================================================
                          SECURITY FEATURES
================================================================================

✅ Row Level Security (RLS)
   - Only authenticated users can create/edit/delete
   - Public can read events
   - Prevents unauthorized access

✅ Authentication
   - Supabase Auth handles password hashing
   - Session tokens are secure
   - No password stored in frontend

✅ API Security
   - CORS restricts which domains can access API
   - API keys are environment-specific
   - Sensitive keys not exposed

✅ Storage Security
   - Images stored separately from database
   - Public bucket but individual permissions
   - Admin can delete images

✅ Best Practices
   - No hardcoded secrets
   - No API keys in version control
   - HTTPS enforced in production
   - Regular security audits recommended
